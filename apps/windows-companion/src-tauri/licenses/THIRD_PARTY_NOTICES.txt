DreyzeStore Companion includes or builds with the following third-party components:

zsign
Copyright (c) 2026 zhlynn. Licensed under the MIT License. The Windows signer is
built from upstream revision 614caa8d1ca949e260e5746144aa52d27a4b08d6. The local
build patch adds length-prefixed password input on stdin and makes a failed
post-sign executable check fail the signing command. Source and patch script:
https://github.com/zhlynn/zsign/tree/614caa8d1ca949e260e5746144aa52d27a4b08d6
See zsign-MIT.txt.

pymobiledevice3
The device service is an optional user-installed dependency and is not bundled
or modified by DreyzeStore. Upstream is licensed under GNU GPL v3.0. Users install
it separately along with the classic iTunes Apple Mobile Device Service.
https://github.com/doronz88/pymobiledevice3

isideload
The local experimental Apple Account provisioning integration links isideload
0.4.0 from https://github.com/nab138/isideload at commit
52b504c2cd706a9e415109b0be9e137168034f5e. Upstream license metadata is MIT;
the MIT notice is included in isideload-MIT.txt. No upstream source was copied.

3100109c6a967375dec78f018be5f4a42cd1bdd9. License: MPL-2.0. Its license is
included in isideload-apple-codesign-MPL-2.0.txt. No source was copied.
